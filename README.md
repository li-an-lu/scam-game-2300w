# 《2300萬分之1》

台灣有 2300 萬人，你是其中一個。

一出生，你的存款、警覺、人際和心理就已經擲骰決定好了。接下來你一年一年長大，第一次打工，搬出家裡，談戀愛，結婚，看著孩子長大。每一個選擇都算數，人生也不能重來。

詐騙不會先打招呼。它可能是童年一則轉傳的訊息，是求職時一份「輕鬆高薪」的工作，是一段你真心投入的感情，也可能是半夜孩子打來的一通電話。你不會知道哪一刻就是那一刻。

遊戲裡每一段劇情都取材自真實資料，包括 165 打詐統計、法院判決，還有受害者親身分享的經歷。每個結局都附一張去識別化的真實案件卡，再帶你回頭看「你錯過的破綻」。

上當的人不笨，往往只是太真誠。玩一次，看看你的人生會走到哪裡。

## 專案結構

- `gen_*.py`：各線事件生成器（人生、家庭、投資、車手、購物等）
- `STORY-TEXT-ALL.md` / `.docx`：完整劇本文字
- `STORY-TEMPLATE.md`：劇情撰寫範本
- `HANDOFF-v*.md`：版本交接說明
- `childhood-events-full.md`：童年階段內容（被動謊言 + 正面事件）
